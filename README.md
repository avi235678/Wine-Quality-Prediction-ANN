🍷 Wine Quality Prediction using Artificial Neural Network (ANN)

📌 Project Overview

This project focuses on predicting wine quality using an Artificial Neural Network (ANN) based on its physicochemical properties.

The model is trained using the Wine Quality dataset and predicts wine quality scores based on input features.

🎯 Project Objectives

- Understand and preprocess the Wine Quality dataset.
- Build an Artificial Neural Network using TensorFlow and Keras.
- Train and evaluate the ANN model.
- Predict wine quality using input features.

🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras
- Jupyter Notebook

📂 Project Structure

- "data/" – Dataset files
- "notebooks/" – Jupyter Notebook implementation
- "models/" – Trained model files
- "app/" – Application files

⚙️ Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Scaling
5. ANN Model Building
6. Model Training
7. Model Evaluation
8. Quality Prediction

🚀 Applications

- Wine quality analysis
- Quality assessment
- Data-driven decision making
